
# Real Estate Market Analysis

This project analyzes a real-estate property dataset to identify pricing patterns, locality-level trends, property characteristics, builder performance, and factors associated with property prices.

The project follows a complete data-analysis workflow:

Raw Kaggle Dataset → Python/Pandas → Data Cleaning → Data Quality Checks → Exploratory Data Analysis → Analytical Metrics → Power BI Dashboard

The objective is to transform raw and inconsistent property data into a clean, analysis-ready dataset and derive meaningful insights that can support real-estate market analysis and decision-making.
